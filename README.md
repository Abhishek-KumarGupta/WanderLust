# 🌍 WanderLust

A full-stack travel listing web application inspired by Airbnb. Users can browse, create, edit, and review travel listings.

## 🚀 Features

- User Authentication (Signup/Login)
- Create, Edit & Delete Listings
- Upload Images with Cloudinary
- Add Reviews & Ratings
- Flash Messages
- Responsive UI
- Session Management

## 🛠️ Tech Stack

- Node.js
- Express.js
- MongoDB Atlas
- Mongoose
- EJS
- Bootstrap 5
- Passport.js
- Cloudinary
- Mapbox

## 📂 Project Structure

```
controllers/
models/
routes/
views/
public/
utils/
```

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/Abhishek-KumarGupta/WanderLust.git
```

2. Go to project folder

```bash
cd WanderLust
```

3. Install dependencies

```bash
npm install
```

4. Create a `.env` file

```env
ATLASDB_URL=your_mongodb_url
CLOUD_NAME=your_cloudinary_name
CLOUD_API_KEY=your_api_key
CLOUD_API_SECRET=your_api_secret
SECRET=your_session_secret
MAP_TOKEN=your_mapbox_token
```

5. Run the project

```bash
nodemon app.js
```
